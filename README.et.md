# SMART VAC MEDIA COMPRESSOR

Kerge, portatiivne PyQt6 töölaua utiliit agressiivseks pakk-töötluseks piltide ja videote jaoks. Loodud nutikate heuristiliste reeglite, kiire üheklikkise konversiooni ja kohandatava tumeda režiimi esteetika jaoks.

## Versioon
0.0.1

[🤍 Toetage arendajat](https://buymeacoffee.com/vacuum34)

## Funktsioonid
- **Pakk-töötlus**: lohistage faile või kaustu kiireks mitme lõnga konversiooniks.
- **Nutikas auto**: intelligentselt otsustab parima kompressiooni meetodi sõltuvalt faili tüübist.
- **Piltide konversioon**: WebP, AVIF, JPG, PNG, TIFF, ICO.
- **Video konversioon**: AV1, HEVC, H.264 koodekid riistvarakõrdega (kui saadaval).
- **Portatiivsus**: täielikult iseseisev, töötab kohe süsteemi reostamata.
- **Kohandatav UI**: tumeda režiimi esteetika teema konfiguratsiooniga.

## Installimine
1. Kloonige see repopositoorium
2. Installige Python 3.11 või kõrgem
3. Installige sõltuvused: `pip install -r requirements.txt`
4. Käivitage rakendus: `python SMART_VAC_COMPRESSOR.pyw`

## Kasutamine
- Käivitage rakendus
- Lohistage faile või kaustu pakk-töötluseks
- Valige kompressiooni seaded ja formaadid
- Klõpsake konverteerimiseks kiireks töötluseks
- Jälgige edenemist reaalajas

## Konfiguratsioon
- Redigeerige `theme_config.json` UI kohandamiseks
- Kohandage kompressiooni parameetreid seadete paneelil
- Riistvarakõrde tuvastus on automaatne
