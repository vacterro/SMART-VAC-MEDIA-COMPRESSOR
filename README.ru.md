# SMART VAC MEDIA COMPRESSOR

Легкая портативная утилита PyQt6 для агрессивной пакетной компрессии изображений и видео. Разработана для умных эвристик, быстрого однокликового преобразования и настраиваемой темной темы.

## Версия
0.0.1

[🤍 Поддержать разработчика](https://buymeacoffee.com/vacuum34)

## Возможности
- **Пакетная обработка**: Перетащите файлы или папки для быстрого многопоточного преобразования.
- **Умный авто**: Интеллектуально выбирает лучший метод компрессии в зависимости от типа файла.
- **Преобразование изображений**: WebP, AVIF, JPG, PNG, TIFF, ICO.
- **Преобразование видео**: Кодеки AV1, HEVC, H.264 с аппаратным ускорением (если доступно).
- **Портативность**: Полностью автономно, работает из коробки без загрязнения системы.
- **Настраиваемый интерфейс**: Темная тема с конфигурацией тем.

## Установка
1. Клонируйте этот репозиторий
2. Установите Python 3.11 или выше
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите приложение: `python SMART_VAC_COMPRESSOR.pyw`

## Использование
- Запустите приложение
- Перетащите файлы или папки для пакетной обработки
- Выберите настройки компрессии и форматы
- Нажмите преобразовать для быстрой обработки
- Следите за прогрессом в реальном времени

## Конфигурация
- Отредактируйте `theme_config.json` для настройки интерфейса
- Настройте параметры компрессии в панели настроек
- Обнаружение аппаратного ускорения автоматическое
